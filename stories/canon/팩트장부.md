# 팩트 장부 (연속성 파일)

여러 멘트에 반복해서 나오는 사실을 **한곳에 고정**해 두는 파일이다. 새 멘트를 쓰기 전에 먼저 여기서 찾아 쓰고, 새로 확인한 사실은 여기에 추가한다. 같은 인물·숫자가 멘트마다 다르게 나오는 것을 막는다.

- 표기: ✅ 확인됨 / ⚠️ 자료마다 다름·논쟁 / ❓ 미확인(쓰려면 확인 필요)
- 각색 금지 영역(상품 효능·가격·희소성, 안전·의학 정보)은 ✅만 쓴다.
