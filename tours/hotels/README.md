# 호텔 정보

호텔 하나에 파일 하나: `tours/hotels/<지역>-<호텔명>.md`. 가이드가 준 정보를 그대로 적고, 확인 날짜를 남긴다.
길버트는 손님 문의가 오면 이 파일 내용만으로 답한다. 없는 정보는 "등록된 정보에 없음".

## 권장 항목 (있는 것만)
- 기본: 정식 명칭(영문/베트남어), 주소, 전화, 체크인·체크아웃 시간
- 시설: 수영장(위치·운영시간), 조식(장소·시간), 피트니스, 스파, 루프탑/바
- 객실: 와이파이 이름·비번, 드라이기·슬리퍼·생수 등 비품
- 주변: 해변 거리, 편의점·마트, 환전, 약국, 마사지, 맛집
- 규정: 보증금(Deposit), 얼리 체크인·레이트 체크아웃 요금, 흡연, 두리안 반입 등
- 가이드 메모: 자주 받는 질문, 주의점
