# 호텔 정보

지역 폴더별로 호텔 하나에 파일 하나: `tours/hotels/<지역>/<호텔명>.md` (지역: `나트랑/`, `달랏/`). 안내문 사진은 `<지역>/원본/`. 가이드가 준 정보를 그대로 적고, 확인 날짜를 남긴다.
길버트는 손님 문의가 오면 이 파일 내용만으로 답한다. 없는 정보는 "등록된 정보에 없음".
**손님 안내 메시지 어투**: 가이드가 리드하는 무게감 있는 합쇼체("~입니다", "주의하십시오"). "~해요", "알아 두시면 좋아요" 같은 부드러운 어투는 쓰지 않는다.
**형식**: 이모지·장식 기호 쓰지 않는다. 번호 항목과 "-" 목록, 24시간제(06:00 - 10:00)로 건조하고 포멀하게(가이드 결정 2026-11-26).
**카톡 주의**: 손님 메시지에 물결표(~)를 쓰지 않는다. 카톡이 ~와 ~ 사이를 취소선으로 바꾼다. 시간 범위는 " - " 로 쓴다.
**🔒 가이드 전용** 표시 항목은 삭제하지 않고 보관하되, 손님용 안내 메시지에는 넣지 않는다.

## 권장 항목 (있는 것만)
- 기본: 정식 명칭(영문/베트남어), 주소, 전화, 체크인·체크아웃 시간
- 시설: 수영장(위치·운영시간), 조식(장소·시간), 피트니스, 스파, 루프탑/바
- 객실: 와이파이 이름·비번, 드라이기·슬리퍼·생수 등 비품
- 주변: 해변 거리, 편의점·마트, 환전, 약국, 마사지, 맛집
- 규정: 보증금(Deposit), 얼리 체크인·레이트 체크아웃 요금, 흡연, 두리안 반입 등
- 가이드 메모: 자주 받는 질문, 주의점
