→ 기분을 없애는 것보다 **"기분 ≠ 행동"으로 분리**하는 게 진짜 기술. 이걸 해냈다.

### 분석 — 혈당이냐 도파민이냐 → **둘 다, 그리고 서로 키움**

**① 혈당 쪽 (방아쇠)**
- **술은 간의 포도당 생산(당신생)을 막는다.** 다음 날 아침까지 간 탱크가 비어 저혈당 경향↑.
- 밤 11시 피자 = 큰 탄수 + 씨앗기름 → 인슐린 크게 → 술 때문에 간이 받쳐주지 못함 → **새벽 저혈당 → 아드레날린·코르티솔 → 얕은 잠.**
- 아침 공복으로 5시간 활동 → 스트레스 호르몬으로 버팀 → **짜증(아드레날린 성분).**
- 최악 시간이 **공복이 가장 길어진 11:30~13:00**과 정확히 겹침 = 혈당 신호가 강함.
- 밥을 먹고도 30분 더 안 좋았던 건 정상: 먹은 뒤 회복까지 30~60분 걸리고, 간 글리코겐이 빈 날은 더 느림.

**② 도파민 쪽 (바닥 높이)**
- 술 = 도파민을 당겨쓰고 다음 날 **반동으로 바닥이 낮아짐.**
- 새벽 1시까지 게임 = 자기 직전 도파민 스파이크 + 각성 → 다음 날 floor↓.
- 6.5시간 + 술 + 저혈당으로 깨진 잠 = 도파민 수용체 회복 부족 → **무기력(의욕 없음) 성분.**

**③ 서로 주고받는 고리**
- 저혈당 → 코르티솔↑ → 도파민 신호 둔해짐 → 더 무기력
- 도파민 낮음 → 아침 챙기기 같은 "귀찮은 일" 안 함 → 공복 연장 → 더 저혈당

**구별법 (다음에 써먹기)**
| | 혈당 신호 | 도파민 floor 신호 |
|---|---|---|
| 느낌 | 짜증·예민·떨림·조급 | 무기력·재미없음·의욕 없음 |
| 먹으면? | **15~30분 안에 확 나아짐** | 먹어도 그대로 |
| 시점 | 공복이 길어질수록 악화 | 아침부터 하루 종일 평평하게 낮음 |

→ 오늘은 **짜증(혈당) + 무기력(도파민)** 둘 다 있었다.

### 다음 "술 마신 다음 날" 프로토콜
1. **마신 날 밤:** 피자 대신 **우유 + 소금 조금 + 꿀이나 과일**. 너무 많이 먹지 않기.
2. **술 마신 날은 게임 X**, 바로 자기.
3. **기상 30~60분 안에 아침:** 우유, 달걀, 밥이나 과일, 오렌지주스 + 소금 한 꼬집.
4. 오전에 **2~3시간마다 간식**(우유·과일·치즈). 술 다음 날은 간이 못 받쳐주니 내가 넣어준다.
5. 아침 햇빛 + 가벼운 걷기로 floor 올리기.
6. 그래도 짜증이 올라오면 → **"이건 혈당/숙취 신호다, 내가 아니다"** 라벨 붙이고 먼저 먹기.
