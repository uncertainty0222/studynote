# 미토콘드리아를 지키는 법 — 모든 것의 뿌리

> 출처: 《식물성 기름의 배신》(Dark Calories) 발췌 + 개인 통찰(2026).

> [`co-regulation-vagal.md`](./co-regulation-vagal.md), [`adhd-reward-system.md`](./adhd-reward-system.md)
>
> **핵심 깨달음: 모든 것의 근본은 대사. 대사의 근본은 건강한 미토콘드리아.**
> (세포에서 에너지를 만드는 곳이 미토콘드리아 — 에너지가 곧 모든 기능의 토대)

---

## 0. 대원칙
> **씨앗 기름은 식품 공급망에서 최악의 미토콘드리아 독소다.**
> **씨앗 기름을 피하는 것이 미토콘드리아를 보호하는 최선이다.**
전략은 명확·간단: **식물성 기름을 끊는다 + 산화스트레스 줄이는 전략 몇 가지를 덧붙인다.**

## 1. 🥩 단백질 섭취를 늘린다
- 자연식품으로 단백질을 충분히. (책 부록A 계산표 = 필요량 지침)
- → 우리 노선: 소고기·달걀노른자·레버·생선. 매 끼 단백질.

## 2. ⚙️ 미네랄에 신경 쓴다
- 항산화 효소엔 미네랄이 필수: **철분·마그네슘·셀레늄·망간·구리.**
- 음식으로 부족하면 영양제로 보충. (→ 페리틴 등 검사로 확인)

## 3. 🐟 오메가 과잉을 피한다
- **오메가-3가 심각하게 부족한 게 아니면 생선유 보조제 권하지 않음.**
- (생선유 = 산화 잘 되는 PUFA. 우리가 이미 얘기한 그 이유.)

## 4. 🚫 환경호르몬을 멀리한다
미토콘드리아에 영향 주는 환경호르몬 중 강력한 것들:
- **흡연**(대마초 등 포함), **대기오염**
- **프탈레이트**(플라스틱 용기에 담긴 것 먹고 마실 때) → 유리·스테인리스 용기 선호
- **중금속**(납·수은·비소)
- **PABA**(일부 선크림 성분)

## 5. 😴 꿀잠과 운동
- **충분한 수면 + 규칙적 운동**도 미토콘드리아 건강·기능 유지에 중요.
- → 우리 노선: 아침 햇빛·규칙적 수면·중강도 운동(전투 아닌 연주 모드).

## 🧭 큰 그림 — 왜 이게 "모든 것의 뿌리"인가

우리가 그동안 나눈 게 사실 **전부 미토콘드리아/대사 한 점으로 수렴**한다:

| 우리가 다룬 것 | → 미토콘드리아·대사와의 연결 |
|---|---|
| **PUFA 제거**(시드오일) | 최악의 미토콘드리아 독소 제거 = 핵심 |
| **혈당 안정**(저혈당 다리) | 세포에 안정적 연료 공급 = 에너지 유지 |
| **철분·미네랄** | 항산화 효소·에너지 대사의 재료 |
| **수면·햇빛·운동** | 미토콘드리아 기능 유지 |
| **호흡·각성 조절**(스트레스↓) | 만성 스트레스는 대사를 갉아먹음 |
| **ADHD 도파민·에너지** | 뇌 = 에너지 부족(미토콘드리아 문제)의 최전선 |
| **케토 vs 슬로카브 판단** | "케톤"이 아니라 "세포 에너지 유지"가 최우선 |

> **결론: 좋은 지방(무 PUFA) + 안정된 연료 + 재료(미네랄·단백질) + 회복(수면·운동·진정)**
> = 미토콘드리아가 에너지를 잘 만드는 몸 = 신체·정신 건강의 뿌리.
> **증상을 좇지 말고, 에너지(대사)를 본다.**
