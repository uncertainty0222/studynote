## 0. 한 줄
**흥분(교감·아드레날린) = 연료를 왕창 쓰고 조금 얻는 저효율 연소 + 크래시.**
**차분(부교감·미토콘드리아) = 연료를 알뜰히 완전연소하는 고효율 + 안정.**

## 1. 아드레날린의 임무 = "비상 질주 연료 투하"
투쟁-도피 호르몬. 당장 뛰거나 싸우게 연료를 확 방류:
- 간 글리코겐 분해 → **혈중 포도당 급방류**, 포도당신생, 지방분해.
- 혈액이 갑자기 연료로 넘침 (근육이 즉시 태우라고).

## 2. 왜 "비효율"인가 (3가지)
1. **안 쓸 근육을 위한 연료.** 질주·격투용인데 앉아서 게임 → 태울 활동이 없음 → 갈 곳 없는 포도당만 넘침.
2. **스파이크 → 크래시(롤러코스터).** 남는 포도당 → 인슐린 과잉 방출 → 혈당이 정상 아래로 추락(두근·멍·허기). **시작보다 더 낮게 끝남.**
3. **★ 저수율 연소 (핵심):**
   - 미토콘드리아 완전연소(산소 O): 포도당 1개 → **ATP ~30개+** (고효율·깨끗)
   - 스트레스식 급속 해당(무산소): 포도당 1개 → **ATP 2개 + 젖산** (저효율·찌꺼기)
   - → 같은 포도당을 태워도 에너지를 **1/10만** 뽑음. 연료 낭비 + 젖산.

## 3. 비유
> 연료탱크를 통째로 엔진에 쏟고 레드라인으로 돌리는데 정작 질주는 안 함(앉아서 게임).
> → 연료 낭비, 저효율·지저분 연소(젖산), 탱크 텅 비어 시동 꺼짐(크래시).

## 4. 반대 = 차분(효율 모드)
부교감(rest&digest) → 미토콘드리아 산소 완전연소 → ATP 30개+, 혈당 안정, 크래시·젖산 없음.
= "명징한 현존"의 대사판. 조용히 크루징하는 고효율 엔진.

## 5. 실전 적용

### ① 이미 포도당이 뿜어진 상태면? → 중강도 유산소로 "써버리기"
- 아드레날린이 근육 쓰라고 방류한 포도당 → **가벼운 계단·산책으로 실제로 태우면** 근육이 흡수(인슐린 무관 GLUT4) → **과잉 포도당 청소 + 크래시 예방 + 도피 회로 완결.**
- 단 **중강도**(헐떡이기 직전까지 X). 이미 과각성 + 저연료면 격하게 하면 아드레날린 더 얹혀 크래시 심해짐.

### ② 먹을까? → 순서가 중요
- **지금 당장 큰 탄수 폭탄 X** (혈당 이미 높음, 아드레날린이 간 저장분을 빌려 올림).
- **순서:** 느린 호흡 + 가벼운 운동으로 진정·청소 → **그다음 균형식**(단백질+지방+느린탄수+소금)으로 **저장분 리필 + 다가올 크래시 예방.** 오늘 저연료였으면 특히 필요.

### ③ 급박한 게임 중에도 효율 모드로 (calm-under-fire 훈련)
> 주의: 목표는 "완전 부교감"이 아니라 **역U자 정점(engaged+relaxed)** — 각성이 **레드라인을 넘지 않게** 유지하는 것. (너무 이완되면 수행 저하)
- **기저 훈련(평소):** 매일 느린 호흡 → 미주신경 브레이크 용량↑. 안 닦아둔 차분은 폭풍에서 못 꺼냄.
- **인게임 앵커:** 긴장 순간(교전·리스폰 사이) **긴 날숨 1번 + 어깨·턱·손 힘 빼기.** (게이머는 긴장 시 숨 참음 → 과호흡·붕뜸 → 그거 방지)
- **위협 재평가:** "이겨야 한다/실수=재앙" → "게임이다, 실수는 데이터." 위협 신호↓ = 아드레날린↓.
- **조기 감지(내수용감각):** "두근거림"이 아니라 "살짝 달아오름" 단계에서 미리 진정. 정점 넘기 전에.
- **연료·카페인:** 안정 혈당 + 과카페인 금지. 빈속 카페인 + 접전 = 아드레날린 스택.
- **점진 노출:** 접전 상황을 "이기기"가 아니라 "차분 유지 연습"으로. 클러치에서 차분했던 렙마다 회로 강화.

> 결론: 각성을 다스리는 건 곧 **대사 효율을 다스리는 것.** 흥분=낭비·크래시 / 차분=고수율·지속.
