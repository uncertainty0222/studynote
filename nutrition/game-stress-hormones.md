# 게임과 스트레스 호르몬 — 도파민은 스트레스 없이 얻을 수 있다

## ⚓ 핵심 한 줄
> **스트레스를 부르는 건 도파민이 아니라 "위협 평가"다.**
> 그래서 판돈 낮은 게임·플로우·햇빛·성취·연결로 **스트레스 없는 도파민**을 얻을 수 있다.

## 1. 게임 중 나오는 두 스트레스 호르몬
| | 아드레날린(노르아드레날린) | 코르티솔 |
|---|---|---|
| 속도 | 초~분, 즉각 | 수십 분~시간, 지속 |
| 느낌 | 두근거림·붕뜸·신경 항진 | 은근한 긴장·예민·잠 안 옴 |
| 언제 | 교전·클러치 순간 | 장시간 세션이 쌓일 때 |

→ 짧은 접전 = 아드레날린, 몇 시간 연속 = 코르티솔까지.

## 2. 장시간 게임의 대사적 영향
**아드레날린:** 간 글리코겐 방출 → 혈당 스파이크 → 안 쓰니 크래시. 저효율 연소(젖산), 연료 낭비.

**코르티솔 (만성이면 더 문제):**
- 근육 분해 → 포도당 생성(특히 빈속) → **근손실**
- **인슐린 저항성↑** → 혈당 더 요동
- **내장지방 축적**
- **단 것·자극 갈망↑** (게임 후 설탕·야식 당기는 이유)
- **수면 질↓** → 다음날 floor 더 낮음 → 또 게임 (악순환)
- 면역·장 기능 저하

## 3. 도파민은 꼭 스트레스를 동반하나? → 아니다
- 도파민 → 노르아드레날린 → 아드레날린은 **같은 조립 라인.** 그래서 위협·경쟁 상황에선 같이 나온다.
- 하지만 스트레스 스위치는 **위협 평가**(지면/랭크/실수/시간압박)다.

**스트레스 거의 없이 도파민이 나오는 상황:**
- **플로우** (실력=난이도, 판돈 낮음): 도파민↑, 노르아드레날린 적당, 코르티솔 낮음
- 코지·캐주얼·싱글·탐험·수집·빌드형 게임
- 배우고 이해하는 "아하!" 순간, 작은 일 완수
- 음악, 햇빛·산책, 따뜻한 사람과의 연결, 운동 후, 호기심·탐험

## 4. 나에게 — "어쩔 수 없다"가 아니다
- 목표가 **낮은 기저 도파민 채우기**라면 게임은 **비효율적 도구.**
  게임 = 순간 스파이크(phasic) + 스트레스 → 끝나면 **기저(tonic)가 오히려 더 낮아짐.**
- 기저를 진짜 올리는 건: 햇빛·걷기·수면·단백질·꾸준한 성취 (스트레스 없이).

**게임을 즐기되 스트레스 비율 낮추기:**
1. 경쟁·랭크 → 캐주얼·협동·탐험형
2. "이겨야 해" → "재밌게 움직이자" (위협 평가 끄기)
3. **먹고 하기** (빈속 + 접전 = 최악)
4. **정점에서 멈추기** (코르티솔 쌓이기 전)
5. 긴장 순간 **긴 날숨**

> 실험: 랭크전 대신 캐주얼/코지 게임 한 판 → 끝나고 몸 느낌 비교. 그 차이가 답이다.

## 5. 코르티솔 타이밍 — 시간보다 "위협 모드"
- 스트레스 시작 후 **15~30분 뒤 상승, 20~40분쯤 정점.** → 강한 접전 한두 판(30분)만으로도 오를 수 있다.
- 스트레스가 끝나면 **대략 1시간 안팎**에 내려옴. 연속으로 하면 내려올 틈 없이 **누적.**
- **시간은 "누적"을 결정할 뿐, 크기는 "위협 평가"가 결정.**

**코르티솔을 키우는 요인 (시간보다 큼):** 위협 평가(랭크·승패·실수 공포) / 빈속(혈당 낮으면 코르티솔로 끌어올림) / 밤늦은 시간(수면 망침) / 연속 플레이

**현실 가이드:** 한 세션 45~60분 → 10~15분 휴식(걷기·물·햇빛) / 랭크전 연달아 X / 먹고 하기 / 자기 2~3시간 전 접전 X / 두근거림·"한 판만 더" = 이미 늦은 신호

> 한 줄: 코르티솔은 시간보다 "위협 모드"에 반응한다. 시간은 누적을 결정할 뿐.
