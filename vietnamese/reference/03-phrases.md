# 03. 상황별 회화 표현 (남부 구어 기준)

`[북부: …]` = 북부에서 주로 쓰는 다른 표현. 한글은 근사 발음.

## 1. 인사·기본
| 베트남어 | 뜻 | 메모 |
|---|---|---|
| Xin chào. | 안녕하세요. | 씬 짜오. 격식. 실제로는 `Chào anh/chị/em`이 더 자연스럽다 |
| Cảm ơn (anh/chị). | 감사합니다. | 깜 언. 남부에서는 `Cám ơn` 철자도 흔함 |
| Không có gì. | 천만에요. | |
| Xin lỗi. | 죄송합니다 / 실례합니다. | 씬 로이 |
| Dạ. | 네. (공손) | 야. [북부: Vâng] |
| Không. | 아니요. | 콤 |
| Hẹn gặp lại. | 또 만나요. | |
| Anh/Chị khỏe không? | 잘 지내세요? | |
| Dạ, khỏe. Còn anh/chị? | 네, 잘 지내요. 당신은요? | |
| Tôi tên là … | 제 이름은 …입니다. | |
| Tôi là người Hàn Quốc. | 저는 한국 사람입니다. | |
| Rất vui được gặp anh/chị. | 만나서 반갑습니다. | |

## 2. 의사소통
| 베트남어 | 뜻 |
|---|---|
| Tôi nói tiếng Việt một chút thôi. | 베트남어는 조금만 해요. |
| Anh/Chị nói chậm lại được không? | 천천히 말씀해 주시겠어요? |
| Anh/Chị nói lại được không? | 다시 말씀해 주시겠어요? |
| Cái này tiếng Việt gọi là gì? | 이거 베트남어로 뭐라고 해요? |
| Tôi không hiểu. | 이해 못 했어요. |
| Hiểu rồi. | 이해했어요. |

## 3. 식당·카페
| 베트남어 | 뜻 | 메모 |
|---|---|---|
| Cho tôi xem thực đơn. | 메뉴 좀 보여 주세요. | 남부 구어 `menu`도 흔함 |
| Cho tôi một tô phở bò. | 소고기 쌀국수 한 그릇 주세요. | `tô` = 큰 그릇(남부). [북부: bát] |
| Cho tôi hai ly cà phê sữa đá. | 아이스 연유커피 두 잔 주세요. | [북부: cốc] |
| Không cay. / Ít cay. | 안 맵게. / 조금 맵게. | |
| Ít đường. / Không đường. | 설탕 조금. / 설탕 없이. | |
| Không bỏ rau thơm. | 향채(허브) 넣지 마세요. | `bỏ` = 넣다 (남부 구어). [북부: cho] |
| Ngon quá! | 정말 맛있어요! | |
| Tính tiền. | 계산해 주세요. | 남부에서 흔함. 공손하게 `Em ơi, tính tiền giùm anh/chị.` |
| Bao nhiêu tiền? | 얼마예요? | 남부 구어 축약 `Nhiêu?` |

- 직원을 부를 때: `Em ơi!` (나보다 어린 직원), `Anh ơi! / Chị ơi!`

## 4. 시장·쇼핑
| 베트남어 | 뜻 | 메모 |
|---|---|---|
| Cái này bao nhiêu? | 이거 얼마예요? | |
| Mắc quá! | 너무 비싸요! | [북부: Đắt quá!] |
| Bớt chút được không? | 좀 깎아 줄 수 있어요? | |
| Có size lớn hơn không? | 더 큰 사이즈 있어요? | |
| Tôi lấy cái này. | 이걸로 할게요. | |
| Tôi chỉ xem thôi. | 그냥 구경하는 거예요. | |

## 5. 택시·길 찾기
| 베트남어 | 뜻 | 메모 |
|---|---|---|
| Cho tôi đến khách sạn … | … 호텔로 가 주세요. | |
| Đi thẳng. | 직진하세요. | |
| Quẹo trái. / Quẹo phải. | 좌회전 / 우회전. | [북부: Rẽ trái / Rẽ phải] |
| Dừng ở đây. | 여기서 세워 주세요. | |
| … ở đâu? | …는 어디예요? | |
| Nhà vệ sinh ở đâu? | 화장실 어디예요? | |
| Xa không? | 멀어요? | |
| Đi bộ được không? | 걸어갈 수 있어요? | |

## 6. 호텔·공항
| 베트남어 | 뜻 |
|---|---|
| Tôi đã đặt phòng rồi. | 방 예약했어요. |
| Mấy giờ trả phòng? | 체크아웃 몇 시예요? |
| Cho tôi xem hộ chiếu. | 여권 보여 주세요. |
| Phòng không có nước nóng. | 방에 뜨거운 물이 안 나와요. |
| Máy lạnh bị hư rồi. | 에어컨이 고장 났어요. (`máy lạnh`, `hư` 남부. [북부: điều hòa, hỏng]) |
| Quầy làm thủ tục ở đâu? | 체크인 카운터 어디예요? |

## 7. 투어 인솔
| 베트남어 | 뜻 |
|---|---|
| Mọi người lên xe nha. | 모두 차에 타세요. |
| Mình tập trung ở đây lúc ba giờ. | 3시에 여기 모입니다. |
| Đoàn mình có hai mươi người. | 저희 단체는 20명입니다. |
| Đã đủ người chưa? | 인원 다 왔나요? |
| Đủ rồi. / Còn thiếu hai người. | 다 왔어요. / 아직 두 명 없어요. |
| Đoàn mình đặt bàn lúc mười hai giờ. | 저희 단체 12시에 예약했어요. |
| Có hướng dẫn viên tiếng Hàn không? | 한국어 가이드 있어요? |
| Khách bị mệt, cần nghỉ một chút. | 손님이 피곤해서 조금 쉬어야 해요. |
| Gần đây có bệnh viện không? | 근처에 병원 있어요? |
