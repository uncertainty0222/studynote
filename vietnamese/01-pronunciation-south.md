# 01. 발음과 성조 — 남부(호찌민) 기준

> 한글 표기는 근사치다. 성조는 한글로 표현할 수 없으므로 반드시 음성으로 확인한다.

## 1. 성조 (표기 6개, 남부 발음 5개)

| 이름 | 부호 | 예 | 뜻 | 남부 발음 특징 |
|---|---|---|---|---|
| ngang | 없음 | ma | 귀신 | 평평하게, 중간 높이 |
| huyền | ` | mà | 그런데 | 낮게 시작해 살짝 내려감 |
| sắc | ´ | má | 엄마(남부) / 볼 | 위로 올라감 |
| hỏi | ̉ | mả | 무덤 | 내려갔다가 올라감 |
| ngã | ~ | mã | 말(馬, 한자어) / 코드 | **남부에서는 hỏi와 거의 같게 발음** |
| nặng | . | mạ | 모 (볏모) | 낮게 내려감. 북부처럼 목을 강하게 막아 끊지 않고 낮게 내려갔다 살짝 올라가는 경향 |

- 남부에서 hỏi와 ngã가 합쳐지는 것은 잘 알려진 특징이다. 단, **철자는 구분해서 써야 한다** (`mả` ≠ `mã`).

## 2. 모음

| 글자 | 근사 발음 | 예 |
|---|---|---|
| a | 아 (길게) | ba (셋) |
| ă | 아 (짧게) | ăn (먹다) |
| â | 어 (짧게) | ấm (따뜻한) |
| e | 애 (입 크게) | em (동생/너) |
| ê | 에 | đêm (밤) |
| i / y | 이 | đi (가다), Mỹ (미국) |
| o | 오 (입 크게, '어'에 가까움) | to (큰) |
| ô | 오 (입 둥글게) | cô (아주머니/선생님) |
| ơ | 어 (길게) | cơm (밥) |
| u | 우 | ngủ (자다) |
| ư | 으 | sữa (우유) |

## 3. 자음 — 남부 발음

| 글자 | 남부 | 북부 | 예 (남부 근사) |
|---|---|---|---|
| b | ㅂ | ㅂ | bánh mì |
| c / k / q | ㄲ (기식 없음) | 같음 | cà phê → 까페 |
| ch | ㅉ | ㅉ | chợ (시장) |
| tr | ㅉ (혀를 말아 올림, ch와 구분하는 화자 많음) | ch와 같아짐 | trà (차) |
| d | **이(j)** | ㅈ(z) | đi와 다름. dạ → 야 |
| gi | **이(j)** | ㅈ(z) | giá (가격) → 야 |
| r | ㄹ(r)/이(j) — 화자마다 다름 | ㅈ(z) | rồi (이미) |
| v | **이(j)** 또는 v | v | vô (들어가다, 남부) |
| đ | ㄷ (내파음) | 같음 | đẹp (예쁜) |
| t | ㄸ (기식 없음) | 같음 | tôi (나) |
| th | ㅌ | 같음 | thịt (고기) |
| kh | ㅋ (목에서 긁는 마찰음) | 같음 | không (아니다) |
| ph | f | 같음 | phở |
| nh | 니(ɲ) | 같음 | nhà (집) |
| ng / ngh | 응(ŋ)으로 시작 | 같음 | người (사람) |
| s | sh에 가까움 (s와 구분 안 하는 화자도 있음) | ㅅ | sáu (여섯) |
| x | ㅅ | ㅅ | xe (차) |

## 4. 받침(끝소리) — 남부의 핵심 변화

| 철자 | 남부 경향 | 결과 |
|---|---|---|
| -n / -ng | 대부분 **-ng(ŋ)** 으로 합쳐짐 | `lan`과 `lang`이 거의 같게 들림 |
| -t / -c | 대부분 **-c(k)** 로 합쳐짐 | `mát`과 `mác`이 거의 같게 들림 |
| -nh | **-n** 에 가깝게 | `anh` ≈ "안" |
| -ch | **-t** 에 가깝게 | `sách` ≈ "삿" |
| -ông, -ung, -óc 등 | 입술을 닫으며 끝냄 | `không` ≈ "콤" |

## 5. 연습용 최소대립쌍
- ma / mà / má / mả / mã / mạ
- ba (셋) / bà (할머니) / bá (백작·으뜸) / bả (그 여자, 남부 구어) / bã (찌꺼기) / bạ (아무렇게나)
- bán (팔다) / bàn (탁자) / bạn (친구)
