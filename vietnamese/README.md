# 베트남어 — 문장 정복 노트

실제로 하고 싶은 말을 한 문장씩 번역받고, 단어를 파고들고, 써먹은 문장은 계속 복습한다.
기준: 남부(호찌민) 구어. 대상: 아내 나나, 처가, 동네 이웃.

## 사용법 (이 폴더에서 Claude에게)
| 이렇게 말하면 | 일어나는 일 |
|---|---|
| "베트남어로: 장모님 음식이 너무 맛있어서 또 먹고 싶어요" | 번역 + `sentences.md`에 S번호로 기록 |
| "단어별로 알려줘" / "○○ 뜻이 뭐야?" | 단어 뜻·용례 설명 + `words.md`에 기록 |
| "S003 써먹었어" (+ 반응·정정 내용) | `✅ 사용함` 표시, 영구 복습 대상 |
| "복습하자" | 써먹은 문장 우선으로 퀴즈 |
