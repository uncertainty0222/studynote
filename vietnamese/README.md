## 권장 학습 순서
| 단계 | 내용 | 확인 방법 |
|---|---|---|
| 1 | 성조 6개 표기 + 남부 5성조 체계, 자음 남부 발음 | "성조 연습" |
| 2 | 대명사·호칭, 기본 어순, 부정·의문 | "작문 교정" |
| 3 | 숫자·돈·시간 | "퀴즈 내줘 (숫자)" |

## 참고
- 남부 방언 특징은 일반적으로 알려진 경향을 정리한 것이며, 개인·지역(호찌민 / 메콩델타 등)에 따라 차이가 있다.
- 발음은 반드시 원어민 음성으로 확인할 것 (예: 사전 앱 음성, 호찌민 출신 화자의 영상).
