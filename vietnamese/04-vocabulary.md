# 04. 주제별 어휘

## 1. 숫자
| 수 | 베트남어 | 메모 |
|---|---|---|
| 0 | không | |
| 1 | một | 21, 31… 의 1은 `mốt` (hai mươi mốt) |
| 2 | hai | |
| 3 | ba | |
| 4 | bốn | 24, 34… 의 4는 `tư`도 사용 (hai mươi tư) |
| 5 | năm | 15, 25… 의 5는 `lăm` (mười lăm, hai mươi lăm) |
| 6 | sáu | |
| 7 | bảy | |
| 8 | tám | |
| 9 | chín | |
| 10 | mười | |
| 20 | hai mươi | 10의 배수는 `mươi` (평성) |
| 100 | một trăm | |
| 105 | một trăm lẻ năm | [북부: một trăm linh năm] |
| 1,000 | một ngàn | [북부: một nghìn] |
| 10,000 | mười ngàn | |
| 100,000 | một trăm ngàn | |
| 1,000,000 | một triệu | |

- 돈 읽기: `50.000đ` = `năm mươi ngàn (đồng)`. 베트남은 천 단위 구분에 점(.)을 쓴다.

## 2. 시간·날짜
| 베트남어 | 뜻 | 베트남어 | 뜻 |
|---|---|---|---|
| Mấy giờ rồi? | 몇 시예요? | giờ / phút | 시 / 분 |
| rưỡi | 반(30분) | hôm nay | 오늘 |
| hôm qua | 어제 | ngày mai | 내일 |
| sáng | 아침·오전 | trưa | 점심때 |
| chiều | 오후 | tối | 저녁 |
| tuần | 주 | tháng | 월 |
| năm | 년 | bây giờ | 지금 |

요일: `thứ hai`(월) · `thứ ba`(화) · `thứ tư`(수) · `thứ năm`(목) · `thứ sáu`(금) · `thứ bảy`(토) · `chủ nhật`(일)

## 4. 남부 vs 북부 어휘 차이 (자주 쓰는 것)
| 뜻 | 남부 | 북부 |
|---|---|---|
| 네(공손) | dạ | vâng |
| 아빠 / 엄마 | ba / má | bố / mẹ |
| 그릇 | chén (밥그릇), tô (큰 그릇) | bát |
| 숟가락 | muỗng | thìa |
| 컵·잔 | ly | cốc |
| 과일 / 과일 분류사 | trái cây / trái | hoa quả / quả |
| 돼지 | heo | lợn |
| 옥수수 | bắp | ngô |
| 비싸다 | mắc | đắt |
| 뚱뚱하다 | mập | béo |
| 마르다 | ốm | gầy |
| 아프다 | bệnh | ốm |
| 우산 | dù | ô |
| 모자 | nón | mũ |
| 들어가다 | vô | vào |
| 사용하다 | xài | dùng |
| 부르다 | kêu | gọi |
| 고장 나다 | hư | hỏng |
| 에어컨 | máy lạnh | điều hòa |
| 돌다(방향) | quẹo | rẽ |
| 1,000 | ngàn | nghìn |

- 주의: `ốm`은 남부에서 "마르다", 북부에서 "아프다". 같은 단어가 뜻이 다르다.

## 5. 자주 쓰는 형용사
