# 나나의 손님 응대 50문장 · 50 câu chăm sóc khách Hàn

손님 응대에 자주 쓰는 순서대로 고른 **50문장**만 외운다. 50개를 확실히 가져가는 게 목표.

Chỉ học **50 câu** dùng nhiều nhất khi chăm sóc khách Hàn. Mục tiêu: thuộc chắc cả 50 câu.

## 파일 · Tệp

| 파일 | 내용 |
|---|---|
| [`top50-print.pdf`](top50-print.pdf) | 인쇄용 A4 2쪽(앞뒤). 들고 다니며 보기 · Bản in A4 2 trang, mang theo người |
| [`flashcards.html`](flashcards.html) | 50문장 연습용 플래시카드. 레벨별, 순서대로/섞기, 🔊 · Thẻ luyện 50 câu |
| [`top50.md`](top50.md) | 같은 50문장 표 · Bảng 50 câu |
| `audio/` | 50문장 녹음 (VoxCPM2로 생성, `tts/` 참고). `NN.wav` 원본, `NN.mp3` 카드용 |
| `src/` | 문장 원본 `data.py`. 수정 후 `cd src && python3 gen.py ..` → `cd .. && node src/make_pdf.js` |

## 레벨 · Cấp độ

| 레벨 | 번호 | 언제 |
|---|---|---|
| Lv.1 | 1–10 | 매일 수십 번 · Ngày nào cũng dùng nhiều lần |
| Lv.2 | 11–30 | 매일 · Mỗi ngày |
| Lv.3 | 31–50 | 상황별 (안전, 병원, 호텔, 첫날, 마지막 날) · Theo tình huống |

순서는 자주 쓰는 정도와 중요도를 기준으로 정한 것이다(사용 빈도 통계가 아니라 판단 기준).

## 하루 10분 · 10 phút mỗi ngày

1. 번호 순서대로 **오늘 3문장**. · Mỗi ngày **3 câu** theo thứ tự số.
2. 🔊 듣고 소리 내서 3번 따라 하기. · Nghe 🔊, đọc to theo 3 lần.
3. 다음 투어에서 손님에게 실제로 1번 말하기 → 종이에 ☐ 체크. · Nói thật với khách 1 lần → đánh dấu ☐ trên giấy.
4. 카드 "전체 50"을 섞어서 가끔 복습. · Thỉnh thoảng trộn "Tất cả" để ôn lại.

## 참고

- 발음 표기는 국립국어원 로마자 표기법 기준. 실제 발음과 다른 부분(예: 늦지 → [늗찌])은 🔊로 확인.
- 🔊는 `audio/NN.mp3` 녹음을 튼다. 파일이 없는 문장만 기기 음성(TTS)으로 읽는다. 속도 버튼으로 1x / 0.8x / 0.6x.
