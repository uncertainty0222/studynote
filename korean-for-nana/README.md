# 나나의 실전 한국어 · Tiếng Hàn dùng ngay cho Nana

기초 문법부터가 아니라 **오늘 바로 쓸 문장**부터 외운다. 손님 응대 문장 + 남편과 쓰는 문장.

Không học từ ngữ pháp cơ bản. Học **câu dùng được ngay hôm nay**: câu nói với khách Hàn và câu nói với chồng.

## 파일 · Tệp

| 파일 | 내용 |
|---|---|
| [`flashcards.html`](flashcards.html) | 휴대폰용 플래시카드. 발음 듣기(🔊), 외운 카드 자동 제외 · Thẻ học trên điện thoại, có nghe phát âm |
| [`phrases.md`](phrases.md) | 전체 문장표 (인쇄용) · Bảng tất cả các câu (để in) |
| `src/` | 문장 원본(`data.py`)과 생성 스크립트. 문장 추가 후 `cd src && python3 gen.py ..` |

## 하루 10분 루틴 · 10 phút mỗi ngày

1. **3문장만** 고른다. 내일 투어 일정에 맞는 카테고리에서. (공항 가는 날 → 1번, 식당 많은 날 → 5번)
   Chọn **chỉ 3 câu**, theo lịch tour ngày mai.
2. 🔊 듣고 소리 내서 3번 따라 한다.
   Nghe 🔊 rồi đọc to theo 3 lần.
3. **미션**: 다음 날 손님에게 1번, 남편에게 1번 실제로 말한다.
   **Nhiệm vụ**: Ngày hôm sau nói thật 1 lần với khách, 1 lần với chồng.
4. 쓴 문장은 "알아요 · Thuộc rồi" 버튼. 끝.
   Nói được rồi thì bấm "Thuộc rồi". Xong.

순서대로 할 필요 없음. 빠진 날이 있어도 다음 날 3문장부터 다시 시작.
Không cần học theo thứ tự. Bỏ một ngày cũng không sao, hôm sau học tiếp 3 câu.

## 문장 공식 5개 · 5 mẫu câu

단어만 바꾸면 문장이 늘어난다. · Chỉ cần thay từ là có câu mới.

| 공식 | 뜻 | 예 |
|---|---|---|
| N + **주세요** | Cho tôi N / Xin hãy… | 물 주세요. (Cho tôi nước.) |
| V + **(으)세요** | Mời / Xin hãy (với khách) | 타세요. 오세요. 드세요. |
| V + **지 마세요** | Xin đừng… | 늦지 마세요. 마시지 마세요. |
| N + **있어요? / 있으세요?** | Có N không? | 질문 있으세요? (Có câu hỏi không ạ?) |
| N + **괜찮으세요?** | N có được không ạ? | 매운 거 괜찮으세요? |

존댓말(-세요, -습니다)은 손님에게, 반말(-어/-아)은 남편에게만.
Đuôi lịch sự (-세요, -습니다) dùng với khách. Đuôi thân mật (-어/-아) chỉ dùng với chồng.

## 시간 말하기 · Nói giờ

**시(giờ)는 순한국어 숫자, 분(phút)은 한자어 숫자.** 투어에서 제일 많이 틀리는 부분.
**Giờ dùng số thuần Hàn, phút dùng số Hán Hàn.**

| giờ | 시 | | phút | 분 |
|---|---|---|---|---|
| 1 | 한 시 | | 5 | 오 분 |
| 2 | 두 시 | | 10 | 십 분 |
| 3 | 세 시 | | 15 | 십오 분 |
| 4 | 네 시 | | 20 | 이십 분 |
| 5 | 다섯 시 | | 30 | 삼십 분 = 반 (rưỡi) |
| 6 | 여섯 시 | | 40 | 사십 분 |
| 7 | 일곱 시 | | 45 | 사십오 분 |
| 8 | 여덟 시 | | 50 | 오십 분 |
| 9 | 아홉 시 | | | |
| 10 | 열 시 | | | |
| 11 | 열한 시 | | | |
| 12 | 열두 시 | | | |

예: 7시 30분 = **일곱 시 삼십 분** = **일곱 시 반**. 오전 = sáng, 오후 = chiều.

## 남편에게 · Gửi chồng

- 나나가 "이거 한국어로 뭐야?" 하고 물으면 짧게 답해 주고, 그 문장을 `src/data.py`에 추가하면 카드가 늘어난다.
- 발음 표기는 국립국어원 로마자 표기법 기준. 실제 발음과 다른 부분(예: 늦지 → [늗찌])은 🔊 듣기로 확인.
- 🔊 듣기는 기기의 한국어 음성(TTS)을 사용한다. 기기에 한국어 음성이 없으면 소리가 안 나거나 다른 언어 음성으로 읽힐 수 있다.
