# 베트남전과 한국 — 통합 스토리 카드

> 어르신(특히 55~60년생 이상) 팀에 거의 매번 나오는 주제. 나트랑 대성당·전쟁사 코스에서 통째로 활용.
> 원칙: 팩트가 아니라 '이야기'로. 민감한 대목은 톤을 낮추고, "양쪽 다 강대국 이념의 피해자" 관점 유지.

---

## 1. 용어 — 월남 vs 월맹
- **월남(越南) = 남베트남** — 글자에 '남(南)'. 사이공·반공·**우리 국군이 도운 쪽**·1975 패망.
- **월맹(越盟) = 북베트남** — '베트민(越盟, 호치민의 공산 독립동맹)'에서 옴. 하노이·공산·**오늘의 통일 베트남을 만든 쪽**.
- 앵커: **"월남의 '남'이 남(南)쪽."** 나머지는 자동으로 북.

## 2. 타임라인 (1954~1975)
- **1954 제네바 협정:** 프랑스 패퇴, **17도선** 임시 분단 + **1956 통일 선거 약속**.
- **1955:** 남에 응오딘지엠 반공 정권(베트남공화국).
- **1956 ★:** 지엠·미국이 **통일 선거 거부**(호치민 압승이 뻔해서) → 영구 분단. *평화의 문이 닫힌 순간.*
- **1955~59:** 지엠 독재·불교/농민 소외 → 불만 축적.
- **1960:** **베트콩(NLF)** 결성, 게릴라전.
- **1961~63:** 케네디, 군사고문단 900→1.6만 명 증원(도미노 이론).
- **1963:** 승려 **틱꽝득 분신** → 11월 지엠 쿠데타·암살 → 혼란.
- **1964 통킹만 → 1965 미군 전투부대 → '미국의 전쟁' 시작.**
- **1975.4.30 사이공 함락 → 북 승리·통일 → 1976 베트남 사회주의공화국.**

## 3. 한국군 파병 (1964~1973)
- **왜 미국이 요청:** 통킹만 후 개입 확대 + 반전 여론·전비 부담 → 존슨의 **'More Flags'**. 험프리 부통령 두 번 특사.
- **왜 한국이 원함:** 최빈국·쿠데타 정권(박정희), 줄어드는 원조 → **돈·안보(주한미군 유지 보장)·정당성**.
- **거래 = 브라운 각서(1966.3.4, 15개 항):** 전투수당(달러)·한국군 현대화·주한미군 감축 없음·한국 기업 일감/차관.
- **규모:** 총 약 34만여 명(동시 5만 유지), **전사 5,099명·부상 11,232명**, 고엽제 후유증.
- **베트남 특수:** 달러 유입 → 경제 도약 종잣돈(한진→대한항공, 현대건설, 경부고속도로).
- ⚠️ 현지에서 자랑조 금지. 민간인 피해 논란(퐁니·하미 등) 존재.

## 4. 한·베 비교 — "같은 시작, 다른 결말"
| | 한국 | 베트남 |
|---|---|---|
| 식민지 | 일본 | 프랑스 |
| 분단 | 1945 / **38선** | 1954 / **17도선** |
| 북 | 김일성·공산·소련 | 호치민·공산·소·중 |
| 남 | 이승만·반공·미국 | 지엠·반공·미국 |
| 전쟁 | 6.25 (1950~53) | 월남전 (~1975) |
| 선거 무산, 거부한 쪽 | **북(소련)** 거부 | **남(지엠·미국)** 거부 |
| 결말 | **정전·분단 지속** | **1975 무력 통일** |
- 직접 연결: 6.25 때 도움받은 한국이 **월남에 파병**(빚을 갚듯).
- 균형: 베트남 통일은 **무력**이었고 전후 **재교육수용소·보트피플** 고통이 따름. 단순히 "부럽다" ❌ → "각자 다른 무게의 결말".

## 5. 통일의 그늘 — 재교육수용소 · 보트피플 (1975~)
- **재교육수용소:** 구 남베트남 군인·관리·지식인 등 **100만 명 이상** 수용(무재판, 강제노동). 약 **6.5만 처형**, 수용 중 **약 16.5만 사망**. 길게는 10년 이상.
- **보트피플(1975~1995):** 약 **200만 명**이 배로 탈출 → **약 80만 도착**, **20만~40만(추정 최대 60만) 해상 사망**(폭풍·굶주림·해적 약탈·강간).
- **화교(Hoa) 박해:** 반(反)부르주아 숙청 + 중국과의 갈등으로 **화교(약 180만, 인구 4%)**가 특히 큰 타격 → 초기 보트피플의 큰 비중.
- **결과:** 미국(리틀 사이공)·호주·캐나다·프랑스로 정착 → **베트남 디아스포라(비엣 끼우)**.

## 6. 손님용 멘트 (정확 + 뭉클)
> "한국과 베트남은 시작이 똑같았어요 — 식민지에서 벗어나자마자 강대국이 허리를 잘랐고(38선·17도선), 공산 북과 반공 남으로 갈려 같은 민족끼리 총을 겨눴죠. 6.25 때 도움받은 우리가 이곳에 파병까지 했고요. **딱 하나가 달랐습니다 — 베트남은 1975년, 피로써지만 하나가 됐고, 우리는 아직 갈라진 채라는 것.**" *(잠깐 침묵)*

**한국 연결(보트피플):** "공산화를 피해 바다로 목숨 걸고 탈출한 이 사람들 — 우리 **흥남철수**로 배에 매달려 남으로 내려온 피난민과 다르지 않죠."
