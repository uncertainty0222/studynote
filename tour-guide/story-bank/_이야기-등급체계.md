# 이야기 등급 체계 — 무엇을 어떻게 말할 것인가

> `_멘트제작-원칙.md`의 **가드레일 1 "안 걸릴 것"**을 실무 도구로 바꾼 것.
> **목적: 픽션을 막는 게 아니라, 픽션을 안전하게 쓰는 것.**

---

## 전제 — 문제는 픽션이 아니다. **액자다**

전설과 전승은 **1급 재료다.** 인류가 수천 년간 검증한 이야기들이고,
지어낸 이야기보다 훨씬 세다. 안 쓸 이유가 없다.

문제가 되는 건 딱 하나다:

> **가짜를 진짜라고 말하는 것.**

호랑이로 변한 침향꾼 이야기를 하는 건 아무 문제가 없다.
**"실제로 있었던 일입니다"**라고 하는 순간 문제가 된다.

**차이는 단어 두세 개다. 그런데 결과가 정반대다.**

---

## ⭐ 그리고 이건 세금이 아니라 기술이다

**이게 핵심이다. 액자를 씌우면 멘트가 약해질 거라고 생각하는데, 반대다.**

| 네가 "이건 사실입니다"라고 열면 | 네가 "이런 이야기가 전해집니다"라고 열면 |
|---|---|
| 손님 머릿속에서 **검증 스위치가 켜진다** | 검증 스위치가 **꺼진다** |
| "진짜야?" "근거가 뭐야?" | **"오, 뭔데?"** |
| 방어 자세 | **듣는 자세** |
| 한 명이 반박하면 **전체가 무너진다** | 반박할 게 없다. 전설은 반박 대상이 아니니까 |

> **전설이라고 밝히는 순간, 손님은 팩트체크를 멈추고 이야기에 들어온다.**
> 이건 손해가 아니라 **몰입 장치**다.

우리가 이미 두 번 확인했다:
- **응엄 응아이 띰 쩜(호랑이 전설)** — 전설로 말해서 강했다
- **나폴레옹 운명선** — 지어낸 걸 인정하고 **진짜 반전**을 붙이니 원본보다 세졌다

# 5등급 체계

멘트 만들 때 **재료마다 등급을 매기고, 그 등급의 오프닝 어구를 쓴다.** 끝이다.

---

## 🅰️ A — 실증 (확인된 사실)

**기록·통계·복수 출처로 확인된 것.**

| | |
|---|---|
| **오프닝** | 제약 없음. **"~입니다"** 단정 가능 |
| **강점** | 반박 불가. 구체적 숫자가 박힌다 |
| **예** | 대만 침향 통계 2,050t / 하버드 85년 연구 / 성 63개→34개 / 1992.1.17 법령 18/HDBT |

> 💡 **A급은 숫자를 아끼지 마라.** 숫자가 곧 신뢰다.

---

## 🅱️ B — 정황 (믿을 만하나 단정 불가)

**근거는 있는데 완전 입증은 아닌 것. 증언·회고·당대 기록.**

| | |
|---|---|
| **오프닝** | **"~라고 합니다"** / **"~라는 기록이 있습니다"** / **"연구진이 내린 결론은"** |
| **강점** | ⭐ **취재하듯 전달하는 톤.** 주장보다 세다 |
| **예** | 조제핀의 마르티니크 예언(1797년 잡지 기사가 근거) / 브로니 웨어의 다섯 가지 후회(증언, 연구 아님) |

> 💡 **B급의 요령: 결론을 네 입에 담지 말고 출처에게 돌려라.**
> "외로우면 심장병 걸립니다" ❌ → **"연구진이 내린 결론은 이거였습니다"** ⭕

---

## 🅲 C — 전승·전설 (사실 아님. 그러나 진짜 문화)

**민담, 설화, 구전. 사실이 아니지만 그 사회가 실제로 공유하는 것.**

| | |
|---|---|
| **오프닝** | **"이런 전설이 있습니다"** / **"이렇게 전해집니다"** / **"옛날 사람들은 이렇게 믿었어요"** |
| **강점** | ⭐⭐ **몰입도 최상.** 검증 스위치가 꺼진다 |
| **예** | 응엄 응아이 띰 쩜(호랑이로 변한 침향꾼) / 각종 지역 설화 |

### ⭐ C급을 최강으로 만드는 법

**전설을 말한 다음, "이 전설이 왜 생겼는지"를 말해라.**

> "…그래서 그는 호랑이가 됐다는 겁니다."
> *(잠깐)*
> **"근데 이게 무슨 뜻이겠어요?"**
> *(3초)*
> **"너무 오래 산에 있으면 사람이 사람이 아니게 된다는 거예요."**
> **"실제로 몇 달씩 산에 있다가 정신이 무너져 돌아온 사람들이 있었습니다."**

**전설(C) → 그 뒤의 실제(A).** 이 2단 구조가 이 체계에서 가장 강한 무기다.
손님은 재미로 들어와서 사실로 나간다.

---

## 🅳 D — 통설·논쟁중 (널리 믿지만 다툼이 있는 것)

**많이 인용되는데 학계 합의가 없거나 반박이 있는 것.**

| | |
|---|---|
| **오프닝** | **"~라는 이야기가 있습니다"** / **"1961년에 이런 조사가 있었습니다"** |
| **⚠️ 필수** | **반박의 존재를 네가 먼저 알고 있어야 한다** |
| **예** | 로세토 효과 / "핀은 프랑스어 filtre에서 왔다" / 나폴레옹 관련 다수 |

### ⭐ D급의 필살기 — 반박을 무기로 바꾼다

손님이 **"그거 반박됐다던데요"** 하면 이렇게 받는다:

> **"맞습니다. 반박한 쪽은 와인 때문이라고 봤어요."**
> *(잠깐)*
> **"근데 공동체든 와인이든, 결국 재밌게 산 게 이유네요."**

**인정하면서 결론이 더 세진다.** 아는 손님을 적이 아니라 **조연**으로 만드는 방법이다.

---

## 🅴 E — 창작·출처불명 (지어낸 것)

**근거가 없고, 버전마다 내용이 다른 것.**

| | |
|---|---|
| **판별법** | ⭐ **세부가 버전마다 흔들리면 거의 항상 E다** (실제 사건은 세부가 고정된다) |
| **오프닝** | **"진짜인지는 모르겠는데, 이런 얘기가 있어요"** |
| **예** | 나폴레옹 운명선 / "대우가 파산한 트럼프를 살렸다" |

### E급 처리법 두 가지

**① 그냥 액자 씌워 쓴다** — "진짜인지는 모르겠는데"
**② ⭐ 반전 재료로 쓴다** — 이게 훨씬 낫다

> ① 이야기를 **그대로** 들려준다 → ② 손님이 감동한다 →
> ③ **"그런데 이거, 지어낸 얘깁니다"** → ④ **진짜는 이랬습니다**

**E급은 버리는 게 아니라 뒤집는 것이다.**
나폴레옹 건이 정확히 이 구조로 원본보다 강해졌다.

---

# 🚫 단 하나의 절대선

**위 다섯 등급 전부 쓸 수 있다. 딱 하나만 하면 안 된다.**

> ## **없는 디테일을 만들어 붙여서 사실처럼 말하는 것.**

**왜 이것만 안 되나 — 도덕 때문이 아니다. 이것만 걸리기 때문이다.**

| 안전 | 위험 |
|---|---|
| 전설을 전설로 말하기 | 전설에 **없던 연도·지명·이름을 붙이기** |
| "이런 얘기가 있어요" | "**1798년 이집트 원정 때**였는데요" ← 원본에 없는 것 |
| 모르는 걸 모른다고 하기 | "동네 사람들이 **비웃었대요**" ← 기록에 없는 추측 |

전설은 아무도 반박 안 한다. **네가 보탠 디테일은 반박당한다.**
그리고 그게 걸리면 **그날 네가 한 모든 멘트가 같이 죽는다.**

> 📌 **한 줄 규칙:**
> **"내가 만든 문장인가, 전해 받은 문장인가."**
> 내가 만든 거면 **사실이라고 말하지 마라.** 그게 전부다.

# 마지막으로

네가 말한 **"행동의 변화"** — 그게 이 체계가 있는 이유다.

재미만 주려면 등급 따질 필요 없다. 아무거나 지어내도 그 순간은 웃는다.
**그런데 사람을 움직이려면 믿어야 하고, 믿으려면 안 걸려야 한다.**

버스에서 한 번 걸린 가이드의 감동적인 이야기는, 그날 이후 **전부 세일즈 토크로 재분류된다.**

> **액자는 이야기를 약하게 만들지 않는다.**
> **액자가 있어야 이야기가 끝까지 산다.**
