# 투어가이드 스토리 시나리오

투어 중 손님의 관심을 끌고, 구매·옵션 참여로 이어지게 하는 이야기 모음.
소재 하나당 파일 하나(`소재명.md`)로 저장한다.

## 작성 원칙

1. **사실이 뼈대, 각색은 살.** 날짜·인물·수치·사건 같은 뼈대는 검증된 사실만 쓴다. 각색은 감정·장면·대사처럼 확인 불가능한 부분에만 넣는다.
2. **각색은 입으로 표시한다.** 멘트에서 각색 부분은 "전해지는 이야기로는", "한번 상상해 보세요", "기록엔 없지만" 같은 말로 연결한다. 손님이 나중에 검색했을 때 거짓이 드러나면 신뢰와 매출을 동시에 잃는다.
3. **상품 효능은 각색 금지.** 건강 효능·원산지·가격 비교처럼 구매 판단에 직접 쓰이는 정보는 사실만 말한다. 허위·과장 표시광고는 법적 제재 대상이 될 수 있다.
4. **출처를 남긴다.** 각 사실 항목에 출처를 적어, 손님 질문에 대비한다.

## 시나리오 파일 구조

```
# 소재명

## 1. 시나리오 (본편)
- 구조: 훅 → 갈등/위기 → 전환점 → 여운 → 행동 연결(방문지·상품)
- 길이: 읽는 데 3~5분

## 2. 사실 / 각색 구분표
| 문장·장면 | 구분(사실/각색/통설) | 근거·출처 |
|---|---|---|

- 사실: 공식 기록·학술자료·공공기관 자료로 확인됨
- 통설: 널리 알려졌으나 1차 사료로 확인되지 않음 (설화·민담 포함)
- 각색: 극적 효과를 위해 만든 부분

## 3. 버스 멘트 버전
- 마이크로 말하는 구어체, 문장 짧게
- 창밖 풍경·도착 시간과 연결하는 멘트 포함
- [쉼], [창밖 가리키며] 같은 연출 지시 포함
- 마지막에 방문지/상품으로 넘어가는 연결 멘트 (강매 느낌 없이)
- 길이: 2~3분 분량
```

## 요청 방법

소재를 지정하면 위 구조대로 작성한다. 함께 주면 좋은 정보:

- 투어 지역·코스 (예: 제주 동부, 경주 1일)
- 손님 구성 (국적, 연령대, 단체 성격)
- 연결할 상품·옵션 (예: 특산품 매장, 선택 관광)
- 이야기가 쓰일 타이밍 (도착 전 버스 안, 현장, 귀가길)
